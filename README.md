# Python CLI Chat Application

This project is a command-line interface (CLI) chat application that interacts with the Mistral 7B model running on a local server at `localhost:1234`. 

## Table of Contents
- [Installation](#installation)
- [Usage](#usage)
- [Contributing](#contributing)
- [License](#license)

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   cd python-cli-chat-app
   ```

2. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage

To start the chat application, run the following command:
```
python src/chat.py
```

Once the application is running, you can type your messages and receive responses from the Mistral 7B model.
